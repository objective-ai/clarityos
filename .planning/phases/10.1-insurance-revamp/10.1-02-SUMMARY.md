## What Was Built

**InsuranceRecordCard — 4 grouped sections:**
- Section 1 (Header): priority badge (Primary/Secondary), payer name, Inactive tag, edit/delete buttons
- Section 2 (Plan Info): 2-column grid — Plan Type, Subscriber ID, Group Number, Plan Name
- Section 3 (Coverage): Copay amount, EligibilityBadge with color dot + stale indicator, Auth # / Expiry / Services (conditional)
- Section 4 (Subscriber): shown only when `relationship_to_subscriber !== "self"`

**EligibilityBadge:** color-coded dot (emerald=active, red=inactive, yellow=pending, orange=expired, gray=unknown) + verified date with orange "⚠" stale indicator when >30 days old.

**Active/Inactive split:**
- `activeInsurance = records.filter(r => r.is_active)` drives the primary/secondary grid
- `inactiveInsurance.length > 0` renders a "Past Insurance" section with `opacity-60`

**InsuranceFormModal — 3 sections with dividers:**
- Plan Information: payer, plan type, priority (read-only), subscriber ID, group #, plan name
- Coverage Details: copay amount, eligibility status select, verified date, auth number, auth expiry, authorized services
- Subscriber Info: relationship, name, DOB (conditional on non-self)
- Active toggle at bottom with explanation text
