Payer selection flow per CONTEXT.md:
```
1. User clicks "Create Superbill" button
2. billingStore.openPayerSelection(encounterId) is called (sets payerSelectionOpen=true)
3. PayerSelectionModal appears (rendered inside SuperbillEditor.tsx):
   a. Fetches patient's insurance from /api/patients/{patientId}/insurance
   b. Shows list: "Primary Medical: Aetna", "Vision: VSP", "Self-Pay"
   c. User selects one option and clicks Confirm
4. Modal calls billingStore.createSuperbillWithPayer(encounterId, payerId, isSelfPay)
5. This POSTs to /api/encounters/{id}/superbill with { billed_payer_id, is_self_pay }
6. Backend returns superbill with line items that have fee_source populated
7. billingStore updates superbill + lineItems state
8. SuperbillEditor renders with fee_source indicators on each line item
```

Change payer flow (on existing superbill):
```
1. In SuperbillEditor, a "Change Payer" dropdown shows current payer
2. User changes payer → billingStore.changeBilledPayer(superbillId, encounterId, newPayerId, isSelfPay)
3. PATCH /api/encounters/{encounterId}/superbill with { billed_payer_id: newPayerId }
4. Backend recalculates non-overridden fees; returns updated superbill + line items
5. billingStore updates state; SuperbillEditor re-renders with new fees
6. Manually overridden items (is_fee_overridden=true) keep their fee unchanged
```
