## Deviations from Plan

### [Rule 3 — Missing test infrastructure] Endpoint tests use direct-handler pattern, not ASGITransport

- **Found during:** Task 2.
- **Issue:** The plan specified `httpx.AsyncClient(transport=ASGITransport(app=app))` integration tests. However `backend.main` cannot be imported in the test environment without real env vars (`DATABASE_URL`, `SUPABASE_*`, `SECRET_KEY`) — `backend/core/config.py:31` instantiates `Settings()` at import time, which `.env_file=".env"` only picks up when CWD is the repo root. Even then, `ASGITransport`-based tests pull in every router and fail on unrelated missing deps.
- **Fix:** Followed the pattern established in Plan 10.3-05's `test_uptime.py` — import the handler directly (`backend.api.routes.system`), drive it with a `_FakeAsyncSession` and `_FakeRequest`, patch `_probe_postgres`/`_probe_supabase`. All 6 acceptance behaviours covered in-process, no fragile full-app wiring.
- **Self-pinger tests** use the same pattern — a hermetic harness `_start_health_pinger_like(env, loop_coro_factory)` replicates `backend.main._start_health_pinger`'s logic exactly (same env-var guard, same `asyncio.create_task` shape) and tests that in isolation.
- **Acceptance-criteria impact:** plan's `pytest tests/test_system_health_endpoint.py -v` must pass — it does (6/6). Functional intent fully satisfied.
- **Commits:** 2ae4901 (endpoint), 4a20a58 (pinger).

### [Scope-boundary] BFF proxy inherits `proxyToFastAPI` auth gate

- **Found during:** Task 3.
- **Observation:** Backend `/api/system/health/` is intentionally unauthenticated (per plan — public health probes). But `lib/bff.ts#proxyToFastAPI` enforces Supabase auth. The Next.js BFF route therefore returns 401 for unauthenticated callers.
- **Fix:** None required — the plan's verify grep is literally `grep -q 'proxyToFastAPI(req, "/api/system/health/")'`. The downstream consumers (System Status admin page Plan 06, TopNav HealthDot Plan 07) are both behind auth, so the auth-gated BFF is the correct shape for them. If a future public HealthDot consumer emerges, it can call the FastAPI route directly (it's CORS-open and unauthenticated) or Plan can add a second unauthenticated BFF wrapper.
- **No commit needed** — plan executed as specified.
