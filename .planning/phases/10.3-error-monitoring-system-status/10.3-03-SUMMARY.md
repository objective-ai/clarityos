## Decisions Made

- Kept `_before_send` as a thin wrapper around `scrub_event` rather than duplicating scrubbing logic — enforces single source of truth in Plan 01's `sentry_scrubber.py` and keeps init module unit-testable
- Pinned sentry-sdk to `>=2.0,<3.0` (v2 is current stable with native FastAPI ASGI integration)
- Release tagged via `os.getenv("GIT_SHA")` — Docker build injects via `ARG GIT_SHA` + `ENV GIT_SHA=$GIT_SHA` (documented in user_setup)
- `init_sentry()` sits between `app = FastAPI(...)` and the exception handler decorator — this is acceptable because `@app.exception_handler` registers a handler but does not wrap the ASGI stack; the actual middleware stack begins at line 29's `add_middleware(CORSMiddleware, ...)`
