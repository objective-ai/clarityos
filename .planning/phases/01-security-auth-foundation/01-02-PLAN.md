         - Configures cookies.getAll() to read from the cookie store
         - Configures cookies.setAll() as a no-op (read-only in route handlers)
         - Returns the supabase client
       - This factory is used by both BFF route handlers and will be used by middleware in Plan 03

    3. Create app/api/audit-logs/route.ts (INF-04):
       - Import NextRequest, NextResponse from 'next/server'
       - Import createServerSupabaseClient from '@/lib/supabase/server'
       - Define FASTAPI_URL from process.env.FASTAPI_URL defaulting to 'http://localhost:8000'
       - Export async GET handler that:
         a. Creates server Supabase client
         b. Calls supabase.auth.getUser() (NOT getSession -- server-side must revalidate)
         c. If no user, returns 401 JSON
         d. Gets the session for the access_token: await supabase.auth.getSession()
         e. Forwards search params to upstream: `${FASTAPI_URL}/api/audit-logs?${searchParams}`
         f. Sends Authorization: Bearer ${session.access_token} header
         g. Sets AbortSignal.timeout(10_000) for 10s timeout
         h. On upstream error, forwards the status code and error body
         i. On timeout, returns 504 Gateway Timeout
         j. On other errors, returns 500 Internal Error

    4. Create app/api/ai-scribe/accept/route.ts (INF-05):
       - Same pattern as audit-logs but for POST method
       - Export async POST handler that:
         a. Creates server Supabase client, validates user (getUser)
         b. Reads the request body as JSON
         c. Extracts encounterId from the request body (the frontend sends { encounterId })
         d. Proxies to: `${FASTAPI_URL}/api/encounters/${encounterId}/ai-scribe/accept`
         e. Sends POST with Authorization header + JSON body
         f. Same error handling pattern (401, timeout, 500)

       - Extracts claims from event->'claims'

       - If found, injects tenant_id and role into claims->'app_metadata' using jsonb_set and jsonb_build_object
       - Returns jsonb_build_object('claims', claims)
       - GRANT EXECUTE to supabase_auth_admin
       - REVOKE EXECUTE from authenticated, anon, public
