Modify `fetchPatientInsurance` (lines 134-139) to use `apiFetch` instead of raw `fetch()`:

```typescript
export async function fetchPatientInsurance(patientId: string): Promise<unknown[]> {
  try {
    const data = await apiFetch<unknown[]>(`/api/patients/${patientId}/insurance`);
    return Array.isArray(data) ? data : [];
  } catch {
    return [];
  }
}
```

Note: `apiFetch` returns camelized keys. The callers in `BillingWorkflow.tsx` cast to `PatientInsurance[]` which uses snake_case fields (e.g., `payer_id`, `payer_name`). Since the BFF route at `app/api/patients/[patientId]/insurance/route.ts` uses `proxyToFastAPI()` which returns the raw FastAPI response (snake_case), and `apiFetch` camelizes the response, the callers will now receive camelCase keys (e.g., `payerId`, `payerName`). However, looking at the `PatientInsurance` type in `types/billing.ts`, it uses snake_case field names. The safest approach: use `apiFetch` but skip key conversion for this call since the type interface uses snake_case. Do this by passing `{ headers: {} }` and manually handling the response — actually, the simplest fix is:

```typescript
export async function fetchPatientInsurance(patientId: string): Promise<unknown[]> {
  try {
    const headers = await getAuthHeaders();
    const res = await fetch(`/api/patients/${patientId}/insurance`, { headers });
    if (!res.ok) return [];
    const data = await res.json();
    return Array.isArray(data) ? data : [];
  } catch {
    return [];
  }
}
```

This adds auth headers while preserving the existing snake_case response format that callers expect. Do NOT use `apiFetch` here because it would camelize keys, breaking the `PatientInsurance` type which uses snake_case field names.

Modify `fetchSuperbillPdfBlob` (lines 145-149) to add auth headers:

```typescript
export async function fetchSuperbillPdfBlob(encounterId: string): Promise<Blob | null> {
  try {
    const headers = await getAuthHeaders();
    const res = await fetch(`/api/encounters/${encounterId}/superbill/pdf`, { headers });
    if (!res.ok) return null;
    return res.blob();
  } catch {
    return null;
  }
}
```

This adds the JWT auth header while still returning a Blob (not JSON), which `apiFetch` cannot handle since it always calls `res.json()`.

const isPublicRoute =
  pathname === "/login" ||
  pathname === "/health" ||
  pathname.startsWith("/intake") ||
  pathname.startsWith("/book") ||

IMPORTANT: This is defense-in-depth only. Each BFF route already validates auth via `proxyToFastAPI()`. The middleware check adds a second layer so that any future BFF route that forgets to use `proxyToFastAPI()` is still protected.
