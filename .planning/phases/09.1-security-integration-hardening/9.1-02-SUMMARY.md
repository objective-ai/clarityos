# Phase 9.1 Plan 02: Payer Fee Schedule Wiring Summary

**One-liner:** Payer-specific fee schedule overlay on BillingWorkflow — fetches rates on payer select/change and applies them to line items and CPT add dropdown with CPT_CATALOG fallback.

## What Was Built

- `fetchPayerFeeSchedule(payerId)` added to `lib/api-client.ts` — fetches `/api/payers/{id}/fee-schedule`, returns `Map<string, number>` for O(1) lookups; returns empty map for self-pay or errors
- `payerFeeMap` state added to `BillingWorkflow`
- Fee map loaded in 3 places: `handleConfirmPayer` (new payer confirmed), `handlePayerChange` (payer swapped mid-review), `useEffect` after load (existing superbill with payer)
- `handleAddCpt` uses `payerFeeMap.get(entry.code) ?? entry.defaultFee`
- `CptAddDropdown` accepts optional `payerFeeMap` prop; `handleSelect` applies payer rate; dropdown list shows payer rate (titled "Payer rate") or base rate (titled "Base rate")
