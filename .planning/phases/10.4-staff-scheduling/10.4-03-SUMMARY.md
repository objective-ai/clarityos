# Phase 10.4 Plan 03: Public Booking DB Schedule Wire-Up Summary

**One-liner:** Wired public booking slot generation to use StaffWeeklySchedule (DB source of truth) with _is_blocked() call added to slot loop so admin-blocked times are actually filtered.

## What Was Done

Task 1 wired `get_availability()` in `public_booking.py` to consult `StaffWeeklySchedule` and filter out `StaffBlockedTime` slots.

**Discovery:** The ORM imports (`StaffWeeklySchedule`, `StaffBlockedTime`), the DB queries, and the `_is_blocked()` helper were already present in the file from a prior partial implementation. However, `_is_blocked()` was defined but never called in the slot loop — the final `available.append()` gate only checked the appointment-overlap flag (`overlaps`).

**Fix applied:** Restructured the slot loop exit condition to call `_is_blocked(slot_start, slot_end)` before appending, using `continue` statements for clarity:

```python
if overlaps:
    continue

if _is_blocked(slot_start, slot_end):
    continue

available.append(slot_start.isoformat())
```
