# Plan: Doctor/Employee Schedule Management

## Context
ClarityOS has appointments and staff models but no way to define *when* each doctor or employee is available, and no way to track actual time worked. This feature adds: (1) full provider availability management — recurring weekly hours, blocked time, shift overview; and (2) employee clock-in/clock-out with attendance logs and CSV payroll export.

---

## What We're Building
1. **Weekly Hours** — per-provider recurring schedule (Mon-Sun, on/off + time range)
2. **Blocked Time** — one-off unavailable periods (lunch, holidays, etc.)
3. **Shift Overview** — read-only weekly grid: who works when across the clinic
4. **Clock-in / Clock-out** — each staff member clocks themselves in/out via a persistent button in the top nav
5. **Attendance Log + Payroll Export** — hours worked per staff per day/week, CSV export for payroll
6. Public booking updated to use DB schedule instead of hardcoded hours

## Phase 1 — Database Models
**File:** `backend/db/models/tenant/clinical.py`

Add `BlockType` enum (StrEnum: lunch, holiday, personal, other) near top with other enums.

Add `StaffWeeklySchedule` model after `Staff`:
- `id`, `tenant_id`, `staff_id` (FK Staff, CASCADE), `day_of_week` (int 0-6), `start_time` (Time), `end_time` (Time), `is_active` (bool, default True)
- UniqueConstraint on `(staff_id, day_of_week)`

Add `StaffBlockedTime` model:
- `id`, `tenant_id`, `staff_id` (FK Staff, CASCADE), `start_datetime` (TZ-aware), `end_datetime` (TZ-aware), `reason` (nullable text), `block_type` (String(20), default "other")
- Index on `(staff_id, start_datetime)`

Add `StaffAttendance` model (after the two models above):
- `id`, `tenant_id`, `staff_id` (FK Staff, CASCADE)
- `clock_in_at` (TZ-aware DateTime, not null)
- `clock_out_at` (TZ-aware DateTime, nullable — null means currently clocked in)
- `date` (Date, indexed — date portion of clock_in_at in clinic timezone, for fast per-day queries)
- `notes` (nullable text)
- Index on `(staff_id, date)`
- UniqueConstraint: only one open record per staff (enforced at API layer, not DB, to avoid locking complexity)

## Phase 4 — Backend API Routes
**New file:** `backend/api/routes/staff_schedule.py`

All routes guarded by `require_permission(ClinicalAction.MANAGE_SCHEDULE)`.

| Method | Path | Action |
|--------|------|--------|
| GET | `/staff/{staff_id}/schedule/` | Fetch weekly schedule |
| PUT | `/staff/{staff_id}/schedule/` | Bulk upsert (delete all → insert new). After `db.flush()`, re-fetch with `selectinload` (not db.refresh — MissingGreenlet rule) |
| GET | `/staff/{staff_id}/blocked-times/` | List blocks (optional from_date/to_date params) |
| POST | `/staff/{staff_id}/blocked-times/` | Create block |
| DELETE | `/staff/{staff_id}/blocked-times/{block_id}/` | Delete block → 204 |
| GET | `/staff/availability/` | All-staff weekly grid (param: week_start=YYYY-MM-DD) |

**Important:** Define literal routes (`/staff/availability/`, `/staff/clock-in/`, etc.) **before** `/{staff_id}/...` routes in the router to avoid FastAPI matching them as UUID path params.

Add clock-in/out + attendance endpoints to `staff_schedule.py`:

| Method | Path | Auth | Action |
|--------|------|------|--------|
| POST | `/staff/clock-in/` | CLOCK_IN_OUT | Create open `StaffAttendance` record for current user. 409 if already clocked in. |
| POST | `/staff/clock-out/` | CLOCK_IN_OUT | Set `clock_out_at = now()` on open record. 409 if not clocked in. |
| GET | `/staff/clock-status/` | CLOCK_IN_OUT | Returns `{ clocked_in: bool, clock_in_at: datetime | null }` for current user |
| GET | `/staff/attendance/` | VIEW_ATTENDANCE | All staff attendance. Params: `from_date`, `to_date` (YYYY-MM-DD). Returns list of `AttendanceRecord`. |
| GET | `/staff/{staff_id}/attendance/` | VIEW_ATTENDANCE | Single staff attendance log. |
| GET | `/staff/attendance/export/` | VIEW_ATTENDANCE | Returns CSV: staff_name, date, clock_in, clock_out, hours_worked. Use `StreamingResponse` with `text/csv`. |

Clock-in logic: get `ctx.staff_id` from `TenantContext`; check for open record (clock_out_at is None); create new `StaffAttendance` with `date = date(now in clinic_timezone)`.

Clock-out logic: find open record by `staff_id`, set `clock_out_at = now()`, flush, re-fetch with `selectinload`.

## Timezone Note
The `date` column on `StaffAttendance` must be derived from `clock_in_at` in the **clinic's timezone** (stored in `tenant.settings_jsonb["timezone"]`), not UTC. Use Python's `zoneinfo` module:
```python
from zoneinfo import ZoneInfo
local_dt = clock_in_utc.astimezone(ZoneInfo(tenant_tz))
record.date = local_dt.date()
```
