# Phase 10.2 — UI Design Contract

> Visual and interaction contract for Phase 10.2: Revamp Schedule & Booking Page.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn/ui (manual — no components.json; components exist in `components/ui/`) |
| Preset | not applicable |
| Component library | Radix UI (via shadcn/ui) |
| Icon library | Lucide React (project standard via shadcn/ui) |
| Font | Plus Jakarta Sans (`var(--font-jakarta)`) |

**No new design system initialization needed.** Existing `components/ui/` components (Button, Badge, Skeleton, Dialog) are the source of truth. Glassmorphism CSS classes in `app/globals.css` are the styling foundation for internal views.

**Two surface contexts exist in this phase:**
- **Internal (staff schedule):** Dark glassmorphism — use `var(--bg-*)`, `var(--text-*)`, glass classes
- **Public booking page (`/book/[slug]`):** Light theme — use `data-theme="light"` on root div OR explicit Tailwind white/gray classes bypassing CSS variables (source: RESEARCH.md Pitfall 5)

## Spacing Scale

Declared values (must be multiples of 4). Source: project 8-point standard.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline element gaps |
| sm | 8px | Card internal padding, compact row gaps |
| md | 16px | Default card padding, form field spacing |
| lg | 24px | Section padding, drawer content padding |
| xl | 32px | Drawer header padding, view container margins |
| 2xl | 48px | Major section breaks, page-level top padding |
| 3xl | 64px | Page-level vertical spacing (public booking wizard only) |

Exceptions:
- Touch targets: minimum 44px (`var(--touch-target)`) — applies to day cells in WeekStrip, Kanban card action buttons, slot picker cells, and all mobile tap targets
- Week strip day cell height: 56px (date number + count badge, taller than standard md)
- Drawer width: 480px on desktop, full-screen on mobile (<768px)
- Flow board column min-width: 220px; gap between columns: 16px

## Typography

All sizes use Plus Jakarta Sans (`var(--font-jakarta)`). Two weights only.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 (regular) | 1.5 | Appointment card fields, drawer body text, form labels, slot picker labels |
| Label | 12px | 600 (semibold) | 1.4 | Status badges, count badges, section headers in Kanban columns, wait time indicator text |
| Heading | 16px | 600 (semibold) | 1.3 | Drawer panel title, patient name on cards, booking wizard step headings |
| Display | 20px | 600 (semibold) | 1.2 | Page section title ("Schedule"), public booking clinic name, wizard step title |

Internal views use `var(--text-primary)` (#F0F2F5 dark / #0F1729 light) for Heading/Display and `var(--text-secondary)` (#8B95A5 dark / #5E6880 light) for Body/Label.

Public booking page uses explicit Tailwind: `text-gray-900` for headings, `text-gray-600` for body, `text-gray-400` for muted.

## Interaction Contracts

### WeekStrip
- Arrow buttons shift displayed week by 7 days; selected day stays highlighted
- Clicking a day cell: immediate visual highlight, triggers `fetchAppointments(date)`, view content replaces below
- Count badge under each day: shows appointment count for the selected day; shows "-" for other days until fetched (source: RESEARCH.md Pitfall 1 / open question 3)
- Selected day cell: accent-colored ring (`border-accent`), day number in `text-accent`, count badge in `bg-accent/10 text-accent`
- Hover state on non-selected day: `bg-white/5` (dark) / `bg-gray-100` (light), 120ms transition

### Appointment Cards
- Left border: 4px solid, color from `STATUS_COLORS[appointment.status]`
- Wait time badge: visible only for `arrived`, `in_pretest`, `in_exam` statuses; amber (#FBBF24) if >15min, red (#F87171) if >30min, no badge otherwise
- Intake status icon: Lucide `Send` (not sent, `text-muted`), `SendHorizonal` with check (sent, `text-info`), `CheckCircle` (submitted, `text-normal`)
- Click anywhere on card (except primary action button): opens AppointmentDetailDrawer
- Primary action button stays on card: "Check In", "Start Exam", or "View Encounter" per status

### AppointmentDetailDrawer
- Slides in from right: `translate-x-full` → `translate-x-0`, 200ms `ease-out-expo`
- Width: 480px, fixed position, `z-50`, backdrop overlay at `z-40` (`bg-black/40`)
- Closing: ESC key, clicking backdrop, or explicit Close button
- Backdrop click closes drawer and clears drawer state
- When booking drawer is open: clicking an appointment card closes booking drawer first, then opens detail drawer after 100ms delay

### BookingDrawer
- Same slide-in animation and width as AppointmentDetailDrawer
- Slot picker grid: 30-min cells for provider's working hours; available = `bg-white/5 hover:bg-accent/10 border-border-subtle`; occupied = `bg-white/2 text-muted cursor-not-allowed`; selected = `bg-accent/15 border-accent text-accent`
- Occupied slot hover: tooltip with occupying patient name (using Radix Tooltip, already available)
- Conflict warning (overbooking): amber banner inside drawer — "This slot is already booked. Staff can still proceed." — does NOT block submission
- Inline new-patient form: expands within drawer (accordion), does not open a new overlay

### Flow Board
- 4 fixed columns, horizontal scroll on desktop if viewport < 1100px
- Upcoming strip: horizontal scroll row above columns showing scheduled/confirmed cards
- Card drag-and-drop: buttons-only fallback unless `@dnd-kit` is approved. Each card shows a "Move to [Next Stage]" button as primary action
- 30s poll: `setInterval` + `clearInterval` on unmount, only active when view mode is "flow"
- New card appearing via poll: subtle `fade-in-up` animation (500ms, already in keyframes)

### View Mode Toggle
- 5 tabs: List / Timeline / Clinic / Flow / Week
- Active tab: accent underline + `text-accent`, 200ms transition
- Persists to `localStorage("schedule_view")`
- Role default applies only on first visit (no localStorage key present)

### Public Booking Wizard
- Step indicator: horizontal pill strip at top, 5 steps; completed = accent fill; current = accent ring; upcoming = `bg-gray-200`
- Forward navigation: "Next" button (accent CTA); backward: "Back" text link (no button styling)
- Step 4 (Patient Info): validation on "Next" click — red helper text appears below invalid fields
- Step 5 (Confirm): shows summary card; CTA = "Confirm Booking"
- Success state: full-card confirmation with green checkmark icon, clinic name, appointment summary
- Mobile: full-width single-column layout, wizard card fills viewport on <640px

## Animation & Motion

All transitions use `var(--ease-out-expo)` = `cubic-bezier(0.16, 1, 0.3, 1)` unless noted.

| Element | Animation | Duration |
|---------|-----------|----------|
| Drawer slide-in | `translateX(100%) → translateX(0)` | 200ms ease-out-expo |
| Drawer slide-out | `translateX(0) → translateX(100%)` | 150ms ease-out-expo |
| Backdrop fade | `opacity 0 → 0.4` | 200ms |
| New card (poll) | `fade-in-up` (already in keyframes) | 500ms |
| View mode tab switch | content cross-fade `opacity 0 → 1` | 150ms |
| Slot picker selection | `background-color` | 120ms |
| Wait time badge color change | `background-color, color` | 300ms |
| WeekStrip day selection | `border-color, color, background-color` | 120ms |

No motion for: card status color borders (static), count badges (static), skeleton loading.

## Responsive Breakpoints

| Breakpoint | Behavior |
|------------|----------|
| `< 640px` (mobile) | Drawers become full-screen overlays; public booking wizard full-width; Flow board columns stack vertically; view mode toggle collapses to icon-only |
| `640–1024px` (tablet) | WeekStrip scrolls horizontally; Flow board horizontal scroll if columns overflow; drawer width 100% |
| `> 1024px` (desktop) | Full layout — 480px drawer, all 4 Flow columns visible, full WeekStrip |

Week strip on mobile: horizontal scroll container, `overflow-x-auto`, `scroll-snap-type-x mandatory`, each day cell `scroll-snap-align-start`.
