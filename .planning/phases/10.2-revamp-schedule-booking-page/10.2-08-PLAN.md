  Fix the error handler at lines 537-538. FastAPI 422 validation errors return `detail` as an array of objects like `[{loc: [...], msg: "...", type: "..."}]`. The current code does `new Error(data?.detail)` which calls `.toString()` on the array.

  Replace the error handling block (lines 536-540) with:
  ```tsx
  } else {
    // FastAPI returns detail as string or array of validation objects
    let errorMsg: string;
    if (Array.isArray(data?.detail)) {
      errorMsg = data.detail.map((d: { msg?: string }) => d.msg ?? "Validation error").join(". ");
    } else {
      errorMsg = data?.detail ?? "Something went wrong. The appointment was not saved — please try again.";
    }
    throw new Error(errorMsg);
  }
  ```

  Also clean up lines 518-519 — send `null` instead of `undefined` for omitted optional fields (JSON.stringify drops undefined keys, but `null` is explicit):
  ```tsx
  dob: dob || null,
  ```
