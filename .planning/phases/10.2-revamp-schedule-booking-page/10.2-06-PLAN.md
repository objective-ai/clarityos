    **Part A: Light theme override in globals.css**

    Per RESEARCH.md Pitfall 5, the safer approach is to NOT use CSS variables in the public page and instead use explicit Tailwind utility classes (`bg-white`, `text-gray-900`, etc.). This avoids variable leakage.

    **Decision: Use explicit Tailwind classes in the public booking page, bypassing CSS variables entirely.** Only use `var(--accent)` (#2DD4BF) for the clinic's accent color since it's intentionally shared.

    Add a minimal scoped override at the end of `app/globals.css` as a safety net:
    ```css
    /* Public booking page — light theme safety net */
    [data-theme="public-booking"] {
      --bg-base: #F8F9FC;
      --bg-surface: #FFFFFF;
      --bg-elevated: #FFFFFF;
      --text-primary: #0F1729;
      --text-secondary: #5E6880;
      --border-subtle: #E2E8F0;
      --glass-bg: rgba(255, 255, 255, 0.95);
    }
    ```

    **Part B: Refactor wizard from 4 steps to 5-step scaffold**

    Restructure the existing 4-step flow into 5 steps:
    1. **Select Visit Type** — radio cards for each visit type with duration label
    2. **Pick Provider** — provider cards with name; "Any Provider" option
    3. **Choose Date + Time Slot** — date picker (placeholder for slot grid, completed in Task 2)
    4. **Enter Patient Info** — first name, last name, email, phone, date of birth
    5. **Confirm** — summary card with all selections

    **Step indicator** (per UI-SPEC):
    ```tsx
    <div className="flex items-center gap-2 mb-8">
      {STEPS.map((step, i) => (
        <div key={step} className={`
          h-2 flex-1 rounded-full transition-colors
          ${i < currentStep ? 'bg-[var(--accent)]' : 
            i === currentStep ? 'bg-[var(--accent)]/50 ring-2 ring-[var(--accent)]' : 
            'bg-gray-200'}
        `} />
      ))}
    </div>
    ```
    Step labels array: `["Visit Type", "Provider", "Date & Time", "Your Info", "Confirm"]`

    **Theme styling throughout:**

    - Wizard card: `bg-white rounded-xl shadow-sm border border-gray-100 p-6 max-w-lg mx-auto mt-12`
    - All text: `text-gray-900` headings, `text-gray-600` body, `text-gray-400` muted
