## What Was Built

### FlowBoard (`components/schedule/FlowBoard.tsx`)
- 4 Kanban columns: Waiting (arrived), Pre-Test (in_pretest), In Exam (in_exam), Done (completed/finalized)
- Upcoming strip: horizontal scroll row showing scheduled/confirmed appointments above columns; hidden when empty
- 30-second polling via `setInterval`/`clearInterval` in `useEffect` — only active when FlowBoard is mounted (viewMode === "flow")
- Wait time badges: `getWaitMinutes` + `getWaitColor` for amber (>15 min) / red (>30 min) coding
- Status transition buttons: "Start Pre-Test" (arrived), "Start Exam" (in_pretest), "View" (in_exam)
- Empty state: "{Column} is clear" per UI-SPEC
- Provider filter applied inline to column cards
- `animate-enter` class for new card fade-in animation

### WeekView (`components/schedule/WeekView.tsx`)
- 7-day time-aligned grid, Google Calendar style
- Time axis: 8 AM to 6 PM in 30-min slots, ROW_HEIGHT=48px matching TimelineView
- Day column headers: day name + date number, today highlighted in accent color
- Appointment blocks absolutely positioned using `clinicHoursMinutes` + ROW_HEIGHT math
- Now indicator (red line) on today's column only
- Loading skeleton: pulsing grid while `isLoadingWeek` is true
- `overflow-x-auto` horizontal scroll on small screens, column min-width 120px

### schedule/page.tsx wiring
- Dynamic imports for both `FlowBoard` and `WeekView`
- `fetchWeekAppointments` triggered when `viewMode === "week"` changes
- `countsByDate` merges `appointments` + `weekAppointments` — WeekStrip shows accurate counts for all 7 days in week view
- `getWeekDays` imported from `@/lib/scheduleUtils` for week range calculation
