    **Step 1: Extend backend list endpoint** in `backend/api/routes/appointment.py`

    Modify `list_appointments` to accept optional `date_from` and `date_to` params alongside existing `date`:
    ```python
    @router.get("/", response_model=AppointmentListResponse)
    async def list_appointments(
        date: str | None = None,
        date_from: str | None = None,
        date_to: str | None = None,
        provider_id: str | None = None,
        db: AsyncSession = Depends(get_tenant_session),
        _user=Depends(get_current_user),
    ):
    ```

    Logic:
    - If `date_from` AND `date_to` are provided: query range `[date_from 00:00, date_to+1 00:00)` in UTC (same timezone conversion pattern as existing single-date logic)
    - If `date` is provided (no range params): existing single-day behavior unchanged
    - If neither: return 422 with "Provide either 'date' or both 'date_from' and 'date_to'"
    - Validate `date_from <= date_to`, return 422 if reversed
    - Limit range to max 31 days to prevent abuse
    - Apply same `provider_id` filter and same `_to_response` mapping as existing code

    The timezone conversion logic (converting local date to UTC datetime range using clinic timezone) already exists for single-date. Extend it:
    ```python
    if date_from and date_to:
        try:
            start_date = _date.fromisoformat(date_from)
            end_date = _date.fromisoformat(date_to)
        except ValueError:
            raise HTTPException(status_code=422, detail="Invalid date format. Expected YYYY-MM-DD.")
        if start_date > end_date:
            raise HTTPException(status_code=422, detail="date_from must be <= date_to")
        if (end_date - start_date).days > 31:
            raise HTTPException(status_code=422, detail="Date range cannot exceed 31 days")
        # Convert to UTC range using same timezone logic as single-date
        local_start = datetime(start_date.year, start_date.month, start_date.day, 0, 0, 0, tzinfo=tz)
        local_end = datetime(end_date.year, end_date.month, end_date.day, 0, 0, 0, tzinfo=tz) + timedelta(days=1)
        utc_start = local_start.astimezone(timezone.utc)
        utc_end = local_end.astimezone(timezone.utc)
    ```
