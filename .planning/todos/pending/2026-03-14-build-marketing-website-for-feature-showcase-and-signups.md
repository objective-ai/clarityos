## Problem

ClarityOS lacks a public-facing marketing website to showcase its features and convert visitors into signups. Without this, there's no way to generate interest or grow the user base beyond manual outreach.

## Solution

Build a dedicated marketing/landing page website that:
- Showcases ClarityOS EHR features (AI Scribe, billing, optical, analytics, etc.)
- Has clear CTAs driving visitors to sign up / request a demo
- Communicates the value prop for small-to-mid ophthalmology/optometry clinics
- Could be a separate Next.js site or a public `/` route on the existing app
