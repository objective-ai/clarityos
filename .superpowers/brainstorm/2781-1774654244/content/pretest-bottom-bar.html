Pre-Test Navigation & Progress

Should the pre-test view have a bottom bar with section navigation and completion checkmarks?

Currently, pre-test has no bottom bar — just 4 accordion sections stacked vertically with a "Ready for Doctor" button at the bottom. The doctor's exam view has the full EncounterBottomTabs with scroll-spy tabs and a status stepper.

A

Bottom Bar with Section Tabs + Checkmarks

Mirror the doctor's EncounterBottomTabs pattern. Bottom bar shows 4 pre-test sections (VA, Pupil/Motility, Instruments, Systemic) as tabs with scroll-spy. Each section gets a checkmark when all required fields in that section are filled.

✓ VA ✓ Pupils ○ Instruments ○ Systemic Ready for Doctor

Pros

  • Tech sees progress at a glance
  • Quick jump to any section
  • Consistent with doctor's exam view
  • "Ready for Doctor" only enables when all sections checked

Cons

  • More complex — need to define "complete" per section
  • 4 sections may feel cramped on mobile
B

Inline Checkmarks Only (No Bottom Bar)

Keep the accordion layout. Add a checkmark icon to each accordion header when that section is filled. No bottom bar — the page is short enough to scroll.

✓ Visual Acuity ▾ ✓ Pupil & Motility ▾ ○ Instrument Readings ▸ ○ Systemic ▸

Pros

  • Simpler implementation
  • Progress visible in accordion headers
  • No bottom bar competing with "Ready for Doctor"

Cons

  • No quick-jump navigation
  • Accordion headers might be scrolled off screen
C

Bottom Bar with Tabs + Checkmarks + "Ready for Doctor" Built In

Same as A, but "Ready for Doctor" is part of the sticky bottom bar (right side), not a separate button at page bottom. The bar is always visible.

✓ VA ✓ Pupils ○ Instruments ○ Systemic Ready for Doctor
↑ Button enables when all sections complete

Pros

  • Everything in one sticky bar — always visible
  • "Ready for Doctor" is gated by completion
  • Tech never loses context on progress
  • Mirrors doctor bottom bar = consistent UX

Cons

  • Most complex to build
  • Tight horizontal space on mobile

💡 Recommendation: Option C — sticky bottom bar with section tabs, checkmarks, and "Ready for Doctor" integrated. Keeps the tech informed and gives them quick navigation. Mirrors the doctor's exam view for UX consistency.
