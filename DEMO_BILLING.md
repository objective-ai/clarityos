# ClarityOS Billing Demo — Optometry Edition

## Demo Flow (5–10 minutes)

### 1. Complete Encounter → Billing in One Screen
- Show how clinical exam data (refraction, laterality, findings) auto-populates the superbill
- **Why it matters:** Existing systems force re-entry of this data — big friction point
- **Demo:** Switch a patient to bilateral, watch CPT codes auto-adjust (laterality auto-pilot)

### 2. E/M Code Intelligence
- **The problem:** This is the biggest billing mistake optometrists make
- Show how ClarityOS auto-selects the correct E/M level based on ROS/complexity (patient-type aware)
- **Demo:** Switch between straightforward vs. complex patient, codes adjust automatically
- **Contrast:** Most other software requires manual code selection or has NO E/M automation

### 3. Specialty-Specific Automation
- **Refraction handling:** Intelligently includes/excludes refraction CPT codes based on exam type
- **Contacts vs. glasses workflows:** Automatic logic, no manual decision trees
- **Why:** This is optometry-specific logic that generic billing software doesn't have

### 4. PDF Superbill Quality
- Show the generated superbill — professional formatting, complete
- Print preview or download option
- **Contrast:** Compare to whatever they're used to (usually manual/clunky)

### 5. Claims Ready
- Show encounters batched and ready to claim
- Status tracking and visibility

## Demo Tips

### Use a Complex Case
Pick a **bilateral refraction with add-on codes and specialty checks** that would normally require 3–4 back-and-forths in other systems. Show how ClarityOS handles it automatically. *That's* the wow moment.

### Key Talking Points
- **Speed:** "See how the superbill is ready before the patient leaves the room?"
- **Accuracy:** "All your codes are verified against your plan coverage and compliance rules."
- **Integration:** "No more copying and pasting between EHR and billing software."
- **Compliance:** "Full audit trail. You can see every code change and who made it."
